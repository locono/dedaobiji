官网地址：dedaobiji.com

## 特点

- 单文件 `index.html`，无需构建步骤，开箱即用
- 公众号二维码已 base64 内联嵌入，页面无外部图片依赖
- 现代卡片式设计，浅色明亮配色，渐变点缀
- 完全响应式，自动适配手机、平板、PC
- 顶部吸顶导航栏（含当天日期）+ 移动端汉堡菜单
- 悬浮「返回顶部」按钮
- 页尾双公众号展示（花生考公 / 考研网盘），点击 QQ 号码可一键复制并提示「QQ 已复制」
